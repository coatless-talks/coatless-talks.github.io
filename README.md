# coatless-talks.github.io

Auto-built project index for [coatless-talks](https://github.com/coatless-talks), deployed to
[talks.thecoatlessprofessor.com](https://talks.thecoatlessprofessor.com/).

Source: [coatless/quarto-org-index](https://github.com/coatless/quarto-org-index).

Rebuilt daily by GitHub Actions plus on push to `main` and on
`repository_dispatch` event `refresh`.
